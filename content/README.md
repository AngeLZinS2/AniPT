# Conteúdo compartilhado

Esta pasta separa conteúdo editorial e dados de demonstração do frontend e do backend.

- `catalog.demo.json`: catálogo offline compatível com os modelos atuais.
- `i18n/pt-BR.json`: textos da interface; as chaves são estáveis e o texto pode evoluir sem recompilar regras de domínio.
- `assets/`: identidade textual reaproveitável.
- `docs/`: decisões de arquitetura, migração e execução.

Dados de catálogo reais continuam pertencendo aos provedores. O catálogo de demonstração serve para desenvolvimento, testes visuais e funcionamento offline.
