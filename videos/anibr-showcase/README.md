# Apresentação AniBR

Vídeo aprovado pelo usuário e exportado com HyperFrames 0.8.159: renders/video.mp4 (H.264, 1920×1080, 30 fps, 30 s, 9.51 MiB, sem áudio).

Edite index.html e compositions/frames/*.html. Não há etapa de geração das cenas. Ativos locais em assets/; capturas originais em capture/assets/. A abertura assets/intro-ola.png foi fornecida pelo usuário. Os dados mostrados são catálogo público, sem nome, lista pessoal ou histórico.

Prévia: npx hyperframes preview --background. Verificar: npx hyperframes check. Exportar após aprovação: npx hyperframes render --quality delivery --output renders/video.mp4. No Windows deste workspace, acrescente ../../.tools/bin ao PATH para FFmpeg/ffprobe.

Resultado final: .hyperframes/final-check.json — zero erros/avisos, execução/layout/contraste aprovados. Exportação usa drawelement e GPU AMD, 22.3 s. A duração e resolução foram confirmadas com ffprobe; a reprodução foi conferida no site.
